关于ik与末端微调,仅供测试
=============================================================
本文档总结：① 机械臂按指定空间坐标运行；② 到位误差的减小方法。
方便接手者直接复用，避免重复计算与调试。

适用对象：创意之星 6 轴机械臂 + CDS 舵机 + UP-Debugger
通信：USB 串口 115200，8N1，AX-12 兼容协议
      读当前位置：FF FF ID 04 02 24 02 [校验]  (位置=0x24~0x25, 0~1023≈0~300°)

-------------------------------------------------------------
一、运动学与限位（已在 description/arm.urdf 与 arm_limits.json）
-------------------------------------------------------------
ID映射：ID1=基座(q0) ... ID6=手掌(q5)，方向全部 = +1（raw 增大=模型正向）
限位(raw/角度/弧度) 与零位(center_raw)：
  ID1: center=830  raw[640,1000]  deg[-55.72, +49.85]  rad[-0.9725,0.8701]
  ID2: center=120  raw[30,200]    deg[-26.39, +23.46]  rad[-0.4606,0.4095]
  ID3: center=140  raw[100,600]   deg[-11.73, +134.90] rad[-0.2047,2.3544]
  ID4: center=480  raw[330,600]   deg[-43.99, +35.19]  rad[-0.7677,0.6142]
  ID5: center=367  raw[250,470]   deg[-34.31, +30.21]  rad[-0.5988,0.5272]
  ID6: center=91   raw[0,200]     deg[-26.69, +31.96]  rad[-0.4658,0.5579]
换算：raw = center_raw + direction * deg * (1023/300)
真实限位下工作空间：最大臂展约 0.23 m（径向），可达体积约 0.011 m^3；
注意是“壳状”区域，很多坐标看似在范围内实则不可达，务必先做可达性验证。

-------------------------------------------------------------
二、向指定坐标运行（复用文件）
-------------------------------------------------------------
文件：
  description/arm.urdf   真实限位模型
  arm_ik.py              可靠 FK/IK（采样热启动 + 有界阻尼最小二乘，可达点误差≈0.1mm）
  circle_test.py         平面画圆（先规划验证，--port 接真机执行）
  lie_down_test.py       向 +x 趴下测试（到位后回车回零位）
  fine_tune.py           到位闭环微调（见第三节）

用法示例：
  # 可靠逆解（任意目标点）
  python -c "import sys; sys.path.insert(0,'.'); from arm_ik import ArmIK; \
  a=ArmIK('description/arm.urdf'); r=a.solve([0.19,0,0.06]); print(r.position_error, r.q)"
  # 平面画圆（默认圆心(0.20,-0.02,0.18) 半径0.02，已实测 24/24 可达）
  python circle_test.py --port COM5            # 或 /dev/ttyUSB0
  # 趴下测试（目标 (0.190,0.000,0.060)m）
  python lie_down_test.py --port COM5

要点：
  - IK 用“上一帧解 + 最近可达采样点”做热启动，轨迹连续、不跳变；
  - 执行前先规划验证（dry-run），任一目标不可达则拒绝执行；
  - 关节空间线性插值 + 慢速(150) + 限位钳制，避免直接跳目标；
  - 目标坐标单位米，基座坐标系，home≈(0.211,-0.014,0.188)。

-------------------------------------------------------------
三、到位误差减小（死区 + 回差 + 闭环微调）
-------------------------------------------------------------
现象：小命令舵机不动、回零位置不准（±5~7 raw ≈ ±2°）。
原因：
  1) 死区：CDS 寄存器 0x1A(顺)/0x1B(逆) 默认=2，误差小于死区舵机不动作；
  2) 齿轮回差/负载：落点与逼近方向相关，存在固定偏置；
  3) 未等舵机停稳就读数会导致“越调越乱”。

对策（已实现 fine_tune.py v2）：
  - 移动后轮询 0x2E 运行标志确认停稳，再多次读数取中值；
  - 直接目标逼近；连续同向且不缩小 → 学习固定偏置(bias)并补偿；
  - 可选把死区调小：--set-deadband 1（0 可能震荡，不建议）。

用法：
  python fine_tune.py --port COM5 --zero --set-deadband 1 --compensate
  python fine_tune.py --port COM5 --zero --dry-run     # 只看现状

实测结果（容差±4 raw）：
  ID1:-4→-4  ID2:+2→+2  ID3:-7→-2(3轮,偏置-7)  ID4:+2→+2  ID5:-5→-4  ID6:-4→-4
  ID3 固定偏置 -7 raw 已写入 arm_limits.json 的 bias_raw，命令 raw = 目标 raw + bias_raw。

建议：把“到位→停稳读回→微调”作为标准收尾；换负载/重装后重测偏置。
