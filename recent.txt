关于ik与末端微调
=============================================================
阅读对象：接手 6 轴创意之星机械臂 + CDS 总线舵机控制的人。
目的：把「按坐标运动」与「到位精度」两块已跑通的方案直接给出来，
省去重复标定、反复试 IK、死区/回差排查的时间。

环境基线
  - 控制器桥：UP-Debugger（Servo 模式），串口 115200 / 8N1
  - 协议：AX-12 兼容；读位置 = FF FF ID 04 02 24 02 [chk]（0x24~0x25，0~1023≈0~300°）
  - 模型：description/arm.urdf（真实限位）；标定：arm_limits.json

-------------------------------------------------------------
0) 一页速查（最重要）
-------------------------------------------------------------
  - 最大臂展约 0.23 m，且可达域是“壳状”——不是实心球，凡目标先做可达性检查
  - IK 用「上一帧解 + 最近采样点」热启动 + 有界阻尼最小二乘，可达点误差≈0.1mm
  - 运动前先 dry-run 验证，不可达则拒绝执行；关节空间插值 + 慢速 + 限位钳制
  - 到位后先等 0x2E 停稳再读数（多读取中值），再决定是否微调
  - ID3 有固定落点偏置 -7 raw，命令 raw = 目标 raw + bias_raw（已入配置）

-------------------------------------------------------------
1) 关节与限位（可直接使用）
-------------------------------------------------------------
轴序：ID1=基座(q0) → ID6=手掌(q5)，方向统一 +1（raw 增大 = 模型正方向）

ID  零位raw   raw限位       角度范围(°)         弧度范围(rad)
1   830       [640,1000]     -55.72 ~ +49.85     -0.9725 ~ 0.8701
2   120       [30,200]       -26.39 ~ +23.46     -0.4606 ~ 0.4095
3   140       [100,600]      -11.73 ~ +134.90    -0.2047 ~ 2.3544
4   480       [330,600]      -43.99 ~ +35.19     -0.7677 ~ 0.6142
5   367       [250,470]      -34.31 ~ +30.21     -0.5988 ~ 0.5272
6   91        [0,200]        -26.69 ~ +31.96     -0.4658 ~ 0.5579

换算公式：raw = center_raw + direction * deg * (1023/300)

-------------------------------------------------------------
2) 按坐标运动（文件与用法）
-------------------------------------------------------------
arm_ik.py        可靠 FK/IK 封装（采样库 + 有界 DLS）
circle_test.py   平面画圆：先规划，--port 接真机执行
lie_down_test.py 向 +x 趴下（默认目标 0.190, 0.000, 0.060 m），到位后回车回零

示例：
  python circle_test.py --port COM5          # 默认圆 圆心(0.20,-0.02,0.18) 半径0.02
  python lie_down_test.py --port /dev/ttyUSB0
  python - <<'PY'
import sys; sys.path.insert(0,'.')
from arm_ik import ArmIK
ik = ArmIK('description/arm.urdf')
r = ik.solve([0.19, 0.0, 0.06])
print(r.position_error, r.q)
PY

说明：目标坐标单位 m、基座坐标系；home ≈ (0.211, -0.014, 0.188)；
默认圆与趴下点均已用真实限位模型验证可达。

-------------------------------------------------------------
3) 到位精度（死区 / 回差 / 闭环微调）
-------------------------------------------------------------
现象：小步命令不动作、回零落点差 ±5~7 raw（≈±2°）。
根因：0x1A/0x1B 死区默认 2（小于死区不响应）；齿轮回差与负载方向相关。

fine_tune.py 做的事：
  1) 移动后轮询 0x2E 至停稳，再取 5 次读数中值（解决“越调越乱”）
  2) 直接逼近目标；连续同向且不缩小时学习固定偏置并补偿
  3) 可选 --set-deadband 1 缩小不响应区（0 易震荡，不建议）

用法：
  python fine_tune.py --port COM5 --zero --set-deadband 1 --compensate
  python fine_tune.py --port COM5 --zero --dry-run

实测（容差±4 raw）：除 ID3 外 0~1 轮到位；ID3 经 3 轮收敛并记录偏置 -7。
建议把「到位→停稳读回→微调」固化为标准收尾；换负载/拆装后重测偏置。
